# 바탕화면 달력

바탕화면 한쪽에 조용히 띄워 두는 작은 달력입니다. Windows용.

## 기능

- **한국 공휴일 자동 표시**: 설날·추석 같은 음력 명절과 대체공휴일을 매년 계산합니다.
- **일정**: 날짜를 누르거나 끌어서 고르고 아래 칸에 적으면 추가됩니다. 날짜를 **오른쪽 클릭**하면 바로 그날 일정을 적을 수 있습니다. 여러 날에 걸친 일정, 색, 메모도 됩니다.
- **잠금**: 오른쪽 위 자물쇠를 누르면 달력이 바탕화면처럼 클릭을 통과시킵니다. 실수로 눌러 옮기거나 고칠 일이 없습니다. 자물쇠를 다시 누르면 풀립니다.
- **크기와 자리**: 가장자리를 끌어 크기를 바꾸고, 위쪽 제목 줄을 끌어 옮깁니다. 창을 넓히면 날짜 칸 안에 일정 이름이 보입니다.
- **겉모습**: 라이트·다크·시스템 테마, 배경 투명도. 처음 켤 때 설정 카드에서 고를 수 있고, 나중엔 메뉴(⋯)나 오른쪽 클릭에서 바꿉니다.
- **윈도우 켤 때 같이 켜기**, **항상 위에 두기**.

일정은 내 PC 안(`%APPDATA%\desk-calendar\events.json`)에만 저장되고, 앱은 인터넷에 연결하지 않습니다.

## 설치

[Releases](../../releases/latest)에서 `desk-calendar-setup-*.exe`를 받아 실행하세요.

서명되지 않은 개인 프로그램이라 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 설치됩니다.

설치하지 않고 쓰려면 `desk-calendar-portable-*.exe`를 받아 바로 실행해도 됩니다.

## 직접 빌드하기

Node.js가 필요합니다.

```bash
npm install
node node_modules/electron/install.js   # npm 11처럼 설치 스크립트를 막는 경우 Electron 본체를 따로 받습니다
npm start                                # 개발용으로 켜기
npm run dist                             # dist 폴더에 설치판·무설치판 exe 만들기
```
